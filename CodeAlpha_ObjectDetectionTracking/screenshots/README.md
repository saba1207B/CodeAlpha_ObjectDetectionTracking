# Screenshots Directory

This directory stores instantaneous frame captures taken during live detection and tracking sessions.

### How to Capture Screenshots:
While the application is running in an active window, simply press the **`s`** key on your keyboard. 

The application will immediately save an uncompressed, high-resolution annotated image into this folder with a timestamp:
`screenshots/tracking_capture_YYYYMMDD_HHMMSS.png`

### Suggested Screenshots for Submission:
1. **`01_webcam_detection.png`**: Live detection showing webcam input with person detection, tracking ID, and confidence badge.
2. **`02_pedestrian_tracking.png`**: Multi-person tracking on street video showing unique IDs and fading trajectory trails.
3. **`03_traffic_tracking.png`**: Multi-class vehicle tracking (cars, trucks, motorcycles) with the heads-up display (HUD) showing high FPS.
4. **`04_terminal_summary.png`**: Terminal session summary showing total frames, elapsed time, processing FPS, and total unique track IDs.
